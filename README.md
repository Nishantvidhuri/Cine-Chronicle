# 🎬 CineChronicle – IMDb Clone with React


## 🚀 Live Demo  
🔗 [Visit Site](https://cinemachronicle.netlify.app)  
🔗 [GitHub Repo](https://github.com/Nishantvidhuri/CineChronicle)

---

## 🛠️ Tech Stack
- React.js
- Redux
- React Router DOM
- Tailwind CSS
- TMDb API (The Movie Database)


---

## ✨ Features

- 🔍 Search movies & TV shows in real-time
- 🎞️ View posters, trailers, ratings, release info
- 📄 Dynamic routing for details page
- 🌐 Data fetched from live TMDb API
- 📱 Fully responsive & mobile friendly
- ⚡ Optimized for fast load using code-splitting

---

## 🧠 What I Learned

- Working with APIs & async data in React
- State management with Redux
- Dynamic routing with React Router
- Styling UI with Tailwind CSS utility classes
